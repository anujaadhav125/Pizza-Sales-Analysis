# 🍕 Pizza Sales Analysis Dashboard | Tableau

## 📌 Project Overview
This project focuses on analyzing pizza sales data using Tableau to gain meaningful business insights. An interactive dashboard was developed to track key performance indicators (KPIs), identify sales trends, and analyze the performance of different pizza categories, sizes, and individual pizzas.

## 🎯 Project Objectives
- Analyze overall pizza sales performance.
- Track important sales KPIs.
- Understand hourly and weekly sales trends.
- Analyze sales by pizza category and size.
- Identify the top 5 and bottom 5 best-selling pizzas.

## 🛠️ Tools & Technologies
- Tableau Public
- MySQL Workbench
- SQL
- CSV Dataset

## 📊 Key Performance Indicators (KPIs)

| KPI | Value |
|---|---:|
| Total Revenue | $817,860.05 |
| Average Order Value | $38.31 |
| Total Pizzas Sold | 49,574 |
| Total Orders | 21,350 |
| Average Pizzas Per Order | 2.32 |

## 📈 Dashboard Visualizations

1. **Hourly Trend for Total Pizzas Sold** – Analyzes pizza sales across different hours.
2. **Weekly Trend for Total Orders** – Shows weekly order patterns.
3. **Percentage of Sales by Pizza Category** – Displays category-wise revenue distribution.
4. **Percentage of Sales by Pizza Size** – Shows sales contribution by pizza size.
5. **Total Pizzas Sold by Pizza Category** – Compares quantities sold across categories.
6. **Top 5 Best-Selling Pizzas** – Analyzes the top 5 pizzas by revenue, quantity, and total orders.
7. **Bottom 5 Best-Selling Pizzas** – Identifies the bottom 5 pizzas by revenue, quantity, and total orders.

## 💡 Key Insights
- Total revenue generated was $817,860.05.
- A total of 49,574 pizzas were sold across 21,350 orders.
- The average order value was $38.31.
- The average number of pizzas per order was 2.32.
- The dashboard helps compare pizza performance by category, size, revenue, quantity, and orders.
